REPRODUCTION
Environment used: Kaggle notebook, 2 x NVIDIA T4 GPUs, Python 3.13, PyTorch 2.x (as preinstalled on Kaggle in November 2026), timm, scikit-learn.
Data (Kaggle copies, accessed 1-2 November 2026): abdallahalidev/plantvillage-dataset ; abdulhasibuddin/plant-doc-dataset.
1) Add both datasets to a Kaggle notebook with a 2 x T4 accelerator. 2) Run the notebook cells in order (self-test, dataset location, run queue).
Settings: 160 x 160 input, 15 epochs, seed 42, one run per configuration (see Table 2 of the manuscript).
Checkpoints (best.pt/last.pt) are not included because of their size; they are regenerated by the notebook.
